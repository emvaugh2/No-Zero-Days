# No Zero Day Challenge


Greetings! I've been on this journey to the cloud for quite some time now (about 4 years) and I'd decided to truly commit to the achieving the role I want as a full-fledged cloud engineer. With that being said, Josh Makador's videos have inspired me to do the No Zero Day Challenge at least for the next 3 months in order to make sure I'm staying consistent with my efforts. 

I don't have a true guideline or objectives for each day because I'm currently in a cloud engineer program BUT I will say I'll be doing at least ONE thing everyday to make sure I'm making some effort to reach my goal. This can be a combination of reviewing topics, the 100 Day of DevOps challenge, making progress on projects in my cloud program, labs on cloud tools to get my skills sharp, LinkedIn SEO, applying for jobs, reaching out to people for job referrals, etc. Anything counts but I'll be posting what I did that day here. 

Some days I may barely get anything done and other days I may go extremely hard. The point here is to stay consistent and honest with myself because it's time to finally get this done. Thanks for tuning in.
